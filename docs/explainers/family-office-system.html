What lives where

  • Public code: the Python package, canonical skills, worker definitions, schemas, and synthetic tests.
  • Private office: authored profiles, append-only financial records, reports, and notebook events.
  • Disposable: SQLite indexes and market caches. Rebuilding an index does not rewrite canonical history.
  • Secret: ignored credentials with restrictive file permissions. Agent instructions forbid reading them; they are not an OS-level sandbox.

Know the boundary

Any office content an advisor reads may be sent to its model provider. A configured private remote receives tracked office data, and a cloud task receives a complete checkout. Read-only application code does not make a brokerage credential incapable of trading if stolen.
